## 模型确认落盘协议

当用户输入 `full-und?` 且判定满足条件（完全理解需求上下文、方案选择明确）时，
**必须通过 write/edit 工具**在需求文档末尾写入以下确认标记节，确认落盘成功后再结束本轮：

```
## 模型确认
- full-und? 理解确认：是
- 确认时间：{date}
```

**注意**：不得仅口头声明确认，必须实际写入文件。

## 作答与写入纪律

- **作答唯一载体**：用户的回答只记录在本文档的 `**答**：` 字段中，不得通过交互式工具（如 `ask_user_question`）收集。
- **写入纪律**：单次 write/edit 载荷不超过约 2KB，超过时拆块追加。
- **完整性核对**：核对文件内容时，一律使用 `read` 工具或 `cat` 直接读取文件，不信任任何经过压缩或包装的 shell 输出（与 rtk 共存指引）。
